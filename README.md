# Guía de Estudio Universitaria

## Descripción

Este proyecto consiste en una guía de estudio digital sencilla, desarrollada como una página HTML básica. Su finalidad es organizar recomendaciones prácticas para planificar el estudio, distribuir el tiempo y mantener un seguimiento de las tareas académicas.

## Objetivo

El objetivo es desarrollar un material digital simple y ordenado que permita presentar consejos de organización académica mediante una página web. El repositorio también sirve para aplicar un flujo básico de trabajo con Git y GitHub, utilizando commits, ramas, issues y pull requests.

## Estructura del repositorio

- `README.md`: documentación general del proyecto.
- `ENTREGA.md`: registro del proceso realizado para el Trabajo Práctico Integrador.
- `proyecto/index.html`: página principal de la guía de estudio.
- `proyecto/styles.css`: estilos visuales de la página.
